# BIM SCHEDULE

Software WEB especializado em planejamento, análise e simulação de obras de engenharia, integrando planejamento tradicional com modelos BIM. Parte integrante do ecossistema **BIMOFFICE**.

## Versão Atual
- **v0.2.0 — Fase 2: Módulo IFC & Visualizador 3D**
  - Processador IFC nativo em Python (`ifcopenshell`).
  - Visualizador 3D interativo via Three.js e Web-IFC no frontend.
  - Extração automática de metadados, GlobalId e tipos de elementos.
  - Correção completa do modo claro/escuro na interface.

---

## Como Executar no Windows
1. Extraia este arquivo ZIP.
2. Dê um duplo clique em **`install.bat`** para instalar todas as dependências do Python e Node.js.
3. Dê um duplo clique em **`start.bat`** para abrir os servidores.
4. Acesse **http://localhost:3000** no navegador.
